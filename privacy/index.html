数隐通（PrivaMask）隐私政策

生效日期：2026 年 9 月 25 日  ·  Effective date: September 25, 2026
中文 English
核心承诺：数隐通全程本地处理：无网络请求、无遥测、无统计、无账号、无 Cookie。你的数据始终留在你自己的电脑上。

1. 处理方式：全程本地

数隐通的全部功能（扫描、识别、脱敏、还原、留痕）均在本机完成。 应用不包含任何联网代码、遥测上报、统计埋点或账号体系，也不使用 Cookie。

2. 数据存放在哪里

数据位置说明
留痕数据库本机数据目录下的 data/privamask.db（SQLite）处理前后文件 hash、脱敏前后文件名、原路径与输出路径（位置）、替换映射
脱敏结果任务输出目录 data/output/<任务时间戳>/（内部保持原目录相对结构）脱敏后的文件副本；源文件只读不改

这些数据只存在于你的电脑，不向任何服务器传输。

3. 含原文的文件，请妥善保管

导出的映射规则 xlsx 与留痕数据库中包含原文（脱敏前真实值）的映射—— 谁持有它们，谁就能把脱敏数据还原为原文。请自行妥善保管，并按需清理； 应用内在还原界面提供按任务清理留痕的入口。

4. 源文件只读

脱敏过程不修改、不移动、不删除你的源文件；所有结果都写入输出目录中的新文件。

5. 卸载与数据残留

卸载应用不会自动删除数据目录 data/（含留痕数据库与输出文件）。 如不再需要这些数据，请在卸载后手动删除该目录。

如有隐私相关问题，请通过微软商店页面提供的支持渠道联系开发者；也可写信到 feedback@weibaba.fun。

7. 关于本网站

本网站为纯静态 HTML 页面：不含统计分析、行为追踪、Cookie 或任何表单， 不向任何第三方服务器发起请求（页面内的外部链接仅在你主动点击时才会跳转）。 网站不记录、不存储任何访问者信息。

Our core promise: PrivaMask processes everything locally: no network requests, no telemetry, no analytics, no accounts, no cookies.

1. Processing: Fully Local

Every PrivaMask feature (scanning, detection, masking, restore, auditing) runs on your machine. The app contains no networking code, telemetry, analytics or account system, and uses no cookies.

2. Where Data Lives

DataLocationNotes
Audit databasedata/privamask.db (SQLite) in the app's local data folderFile hashes before/after, file names before/after masking, original and output paths (positions), replacement mappings
Masked resultsTask output folder data/output/<task timestamp>/ (original relative structure preserved)Masked copies; your source files are read-only
Restored filesdata/output/restore/<task timestamp>/Files produced by restore
Rules & settingsSame local databaseMasking rules, audit switch and other UI settings

This data exists only on your computer and is never sent to any server.

3. Files That Contain Original Values — Keep Them Safe

The exported mapping workbook (xlsx) and the audit database contain mappings to the original (pre-masking) values — whoever holds them can restore the masked data. Keep them safe and clean them up as needed; the restore screen in the app provides per-task audit cleanup.

4. Source Files Are Read-Only

Masking never modifies, moves or deletes your source files; all results are written as new files into the output folder.

5. Uninstall and Leftover Data

Uninstalling the app does not automatically delete the data folder data/ (the audit database and output files). If you no longer need this data, delete the folder manually after uninstalling.

6. Contact

For privacy questions, reach the developer via the support channel on the Microsoft Store listing, or write to feedback@weibaba.fun.

7. About This Website

This website is a set of purely static HTML pages: no analytics, no behavioral tracking, no cookies, no forms, and no requests to any third-party server (external links open only when you click them). The site records and stores nothing about its visitors.
